# معيار القبول البصري والوظيفي — صراع الأساطير

هذا المعيار إلزامي لكل نظام وأصل ومشهد في المشروع. نجاح البناء أو الاختبار البرمجي وحده لا يعني اكتمال العنصر.

## المرجع
- المرجع الأساسي: ملفات وأصول وبيانات Conquer Online Mobile الأصلية التي وفرها صاحب المشروع، وليس نسخة الكمبيوتر ولا التخمين ولا صورًا تقريبية.
- لكل عنصر يجب تسجيل اسم ملف المصدر، بصمته SHA-256، سجل/معرّف المصدر إن أمكن، وطريقة تفسيره.
- إذا تعذر فك تنسيق المصدر أو إثبات معنى الحقول، يوضع العنصر في حالة NEEDS_SOURCE_ANALYSIS ولا تُختلق قيم بديلة.

## حالات العنصر
- NOT_ACCEPTED: لم يكتمل أو لم يُفحص.
- NEEDS_SOURCE_ANALYSIS: مصدره موجود لكن مخططه/حقوله لم تُفهم وتُتحقق.
- IN_PROGRESS: التنفيذ جارٍ.
- BLOCKED: متوقف بسبب نقص مصدر أو صلاحية أو أداة أو قرار.
- ACCEPTED: اجتاز كل بوابات القبول المطلوبة.

## بوابات القبول الإلزامية
1. SOURCE_TRACEABILITY: مصدر أصلي محدد وبصمة/مرجع وسجل تحويل قابل للتتبع.
2. REFERENCE_MATCH: مقارنة موثقة مع المرجع الأصلي في الشكل والنسب والألوان والأيقونات والتأثيرات والسلوك، حسب طبيعة العنصر.
3. FUNCTIONAL_INTEGRATION: مرتبط فعليًا بالأنظمة المعنية (مخزون/وحوش/مهام/تطوير/معدات/خرائط/واجهة)، وليس نموذجًا منفصلًا أو placeholder.
4. RUNTIME_VISUAL_VERIFICATION: ظهور العنصر في مشهد Godot فعلي مع لقطات/تسجيلات، وفحص التحميل والخامات والأنيميشن والاصطدامات والتداخل.
5. AUTOMATED_TESTS: اختبارات آلية للمنطق والبيانات والحالات الحدية.
6. DEVICE_PERFORMANCE: للعناصر المؤثرة على الأداء، اختبار موثق على Redmi Note 11 أو تسجيل profiler موثق؛ محاكاة CI لا تُعد اختبار جهاز.

## شروط ACCEPTED
لا يجوز وضع ACCEPTED إلا عند اكتمال البوابات المنطبقة وتوفير الأدلة. أي بوابة غير مثبتة تعني أن العنصر يظل غير مقبول حتى لو اشتغل الكود أو نجح APK.

## نطاق التدقيق
الشخصيات والفئات، الهيكل العظمي وربط المعدات، الملابس والأسلحة، التوهج لكل مستوى تطوير، الوحوش وحركاتها، جداول الإسقاط ونسبها، المواد والأحجار واستخداماتها، المهام ومتطلباتها، الاقتصاد والتطوير، الخرائط والتضاريس والمباني، واجهة المستخدم والأيقونات، المؤثرات والأصوات، التصادمات والأداء.

## قواعد تمنع الادعاء الزائف
- لا تُستبدل تأثيرات أو قيم أو نسب المصدر بتقديرات من عندنا.
- لا تُعتبر الأشكال البدائية أو المؤقتة أو المجسمات الإجرائية مطابقة للمرجع.
- لا يُعتبر تحويل GLB صالحًا بصريًا لمجرد أن له هندسة قابلة للرسم.
- لا يُعتبر عدد ملفات المصدر أو نجاح استخراجها دليلًا على فهم محتواها.
- أي تعارض بين المصدر والتنفيذ يوقف قبول العنصر ويُسجل كتعارض مفتوح.
- لا تُنشر أصول C3 المشتقة ولا تُفعّل روابط توزيعها دون تصريح توزيع صريح ومراجعة الحقوق.

## طريقة الإغلاق
لكل عنصر تقرير يوضح: المرجع، المصدر، ما نُفذ، ما لم يُنفذ، اختبارات المنطق، المقارنة المرئية، مشاكل الدمج، والأدلة. لا يُغلق إلا بعد اجتياز جميع البوابات المنطبقة.
