# Phase 1 production world asset sources

## Sapphire environment models
- Source repository: https://github.com/nameless525/sapphire
- Pinned source commit: 3b1bdd7a3aa935126cbc39a1109f86661a789a5b
- courtyard.glb and arcade.glb are source-project environment models; the repository MIT license is retained as LICENSE-MIT.txt.
- pavilion.glb is a deterministic glTF conversion of VVayToyek's Chinese Four-corner Pavilion, originally CC0 1.0. The original source and license evidence are retained in PAVILION-SOURCE.md and PAVILION-LICENSE.md.

## Nature models
- Source repository: https://github.com/Hidencod/tge-assets
- Pinned source commit: ea2f2aa1ca8da0898330c97df8a5489976b051d0
- Kenney Nature Kit models are CC0 1.0. The source repository's license is retained as LICENSE-CC0.txt.

All downloaded models are pinned to immutable commits. SHA-256 hashes and GLB structural inventories are in reports/phase1_world_asset_manifest.json. These remain candidate assets until Godot import, visual review, scene integration, collision review, and Android runtime checks pass.
